# 涟漪 Ripple

按日期管理行程，设置开始时间、时长、地点、时间约束和前置行程。时间轴会标出重叠的安排，并沿着依赖关系检查后续行程能否准时开始。Android 版可以自动识别所选应用的新通知，用户确认后将活动加入行程。

## 体验看展流程

1. 点「创建看展示例」。初始计划为 14:00 集合、14:30 入场和 17:00 返程。
2. 点「模拟朋友晚到 40 分钟」，或编辑「与朋友集合」的开始时间。时间轴会提示入场和返程两处冲突。
3. 点「查看冲突」，选择演示场次 15:00 入场，或保留 14:30 的预约并在参观后会合。确认前可以核对时间、时长、地点和依赖变更。
4. 点「确认并更新行程」。刷新或重新启动后可以继续查看已保存的行程。

行程按日期保存在本机，可在日程上方切换日期。升级时，原有行程会保留在首次打开新版当天。行程冲突分析在本机完成，看展场次使用演示数据。

首页的摘要卡片用当天的主要行程作标题。优先显示预约，其次选择耗时最长的行程，时长相同则选开始较早的一项。看展示例显示「周末看展」。

右下角的加号用于添加行程。检测到冲突后，警告卡片右侧会显示「查看冲突」。滚动时间轴时，摘要和警告固定在上方，加号暂时收起。底部导航可在「日程」和「关系」之间切换，关系页显示前置行程和转场时间。

## Android 通知与 AI 提取

1. 在 Android 版打开「通知」，点「开启通知读取权限」，在系统设置中授权「涟漪」。
2. 回到应用查看通知。应用会读取当前仍在通知栏里的通知和授权后收到的新通知，在本机保留最近 7 天内最多 50 条。
3. 点「通知」页顶部的「AI 模型设置」。默认使用 DeepSeek `deepseek-flash`。填写 API 密钥，在「自动提取来源」中勾选应用，再点「保存模型配置」。来源列表来自已收到的通知。需要添加某个来源时，先让该应用发一条系统通知。也可填写其他支持 Chat Completions JSON 输出的 HTTPS 服务地址和模型名称。密钥使用 Android Keystore 加密保存在本机。
4. 所选应用的新通知会由 Android 通知监听服务自动处理。手机联网后将通知的来源、标题、正文和接收时间发送到所选模型服务，结果保存在本机的通知详情中。涟漪会跳过包含常见验证码提示的通知。切换模型服务地址后，新地址从保存时起接收所选来源的新通知。
5. 在事件卡片点「加入行程」，核对或补全日期和时间，再点「保存行程」。已保存的事件可跳转到对应日期的时间轴。取消通知只展示提取结果。

例如，「定于今天 16:00 进行版本测试，请相关人员参加」可以提取为当天 16:00 的测试安排，日期按通知接收时的本地日期计算。模型返回空结果时，应用会对这类包含明确日期、时间和活动的通知在本机补提取。升级后，重新打开仍保存在通知列表中的旧空结果也会触发补提取。

安装 `build/app/outputs/flutter-apk/app-release.apk` 即可使用。Android 版的模型配置和通知读取都在手机上完成。

若通过 APK 安装后，开启通知读取时手机提示「受限制的设置」，在系统的「涟漪」应用信息页打开右上角菜单，选择「允许受限制的设置」，再返回通知读取设置。[Android 说明](https://support.google.com/android/answer/12623953?hl=zh-Han)

## 界面基准

使用原生 Material 3 的配色、组件、圆角和系统字体，尽量少做视觉改造。系统提供动态颜色时直接使用，否则通过 Material 3 生成对应明暗模式的色板。采用原生卡片、右下角 FAB 和底部导航栏。

Android 使用系统字体。Web 预览附带 Noto Sans SC 中文补字，支持离线显示。字体许可证见 [SIL OFL](assets/OFL.txt)。

## 运行和验证

在本目录使用 Flutter 3.50.1、Dart 3.14。Android 构建还需要 JDK 17 和 Android SDK 36。

在 Windows 上构建 Android 版本时，请使用纯英文的工程和 Android SDK 路径。当前工作区可以通过临时盘符映射来构建。

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Web 可用以下方式构建和预览。

```powershell
flutter build web --no-web-resources-cdn
python -m http.server 8781 --bind 127.0.0.1 --directory build/web
```

启动服务器后打开 [本机预览](http://127.0.0.1:8781/)。

## 开源组件

- [Material UI](https://pub.dev/packages/material_ui) 提供 Material 3 控件和简体中文日期、时间界面。
- [dynamic_color](https://pub.dev/packages/dynamic_color) 提供可用平台的系统动态配色。
- [Riverpod](https://pub.dev/packages/flutter_riverpod) 管理行程状态，[shared_preferences](https://pub.dev/packages/shared_preferences) 保存本机行程。
